Project: Student Academic Performance Explorer

Hello. My project is called Student Academic Performance Explorer. It uses a
small simulated dataset to demonstrate how study habits and other learning
indicators can be explored with R and Shiny.

Describe the dataset — show the CSV
The dataset contains 150 simulated student-level records. The unit of analysis
is one fictional student record. The variables include grade level, study hours
per day, attendance rate, assignment completion, extracurricular participation,
parental support, exam score, and a performance band. The dataset was generated
for this class project and is not taken from a real school or external source.
Because the data is simulated, it cannot describe actual students or support
claims about a real population. The relationships are illustrative only.

Show analysis.R and run it
In analysis.R, I import the CSV, inspect its structure, remove rows with missing
values in the analysis fields, and create summary objects. I calculate the
overall average and median exam score, compare average scores across grade
levels and parental-support groups, and calculate the correlation between study
hours and exam score. I also create a bar chart and a scatterplot.

Explain findings — use the actual Console output
The overall average exam score in this generated dataset is [read the value
shown in overall_summary]. The grade-level comparison shows [describe the
highest and lowest averages in grade_summary]. The correlation between study
hours and exam score is [read study_score_correlation]. These are patterns in
simulated data, not proof that one factor causes another.

Show app.R and click Run App
The Shiny app reads the same CSV file. A user can filter by grade level,
parental-support category, and exam-score range. When a filter changes, the
student count, average exam score, average attendance, chart, and table update.
I will change each filter to demonstrate that the results respond to the
selection. If no records match, the app displays a no-results message.
